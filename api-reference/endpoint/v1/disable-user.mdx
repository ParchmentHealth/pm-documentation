---
openapi: "PUT /v1/organizations/{organization_id}/users/{user_id}/disable"
---

## Overview

Disables the user: marks them disabled, downgrades their roles to `member` and blocks sign-in. No request body.

Idempotent: a user who is already disabled returns `200` with `"User is already disabled"`.

Requires the `update:user` scope.

## Response Fields

| Field     | Type   | Description            |
| --------- | ------ | ---------------------- |
| `user_id` | string | Parchment's user ID    |

## Status Codes

| Code  | Status                | Description                                   |
| ----- | --------------------- | --------------------------------------------- |
| `200` | OK                    | User disabled, or already disabled                |
| `400` | Bad Request           | Target user has no email address              |
| `401` | Unauthorized          | Token invalid, or missing `update:user` scope |
| `404` | Not Found             | User not found                                |
| `500` | Internal Server Error | Unexpected server error                       |
