## Overview

Creates a patient in the organization. Parchment looks up the IHI from the HI Service unless you send `ihi_number`.

A repeat `partner_patient_id` is idempotent. No new patient is created and the existing patient is returned with `200`.

Requires the `create:patient` scope.

## Request Example

```json
{
  "partner_patient_id": "PMS-000123",
  "partner_id": "demo",
  "given_name": "Denice",
  "family_name": "SHEA",
  "date_of_birth": "1992-12-16",
  "sex": "F",
  "medicare_card_number": "6951907501",
  "medicare_irn": "1",
  "phone": "0417903853",
  "email": "919@Ausnet.com.au",
  "australian_street_address": {
    "street_number": "163",
    "street_name": "Law Rd",
    "suburb": "Jitarning",
    "state": "WA",
    "postcode": "6365"
  }
}
```

## Response Fields

| Field                  | Type   | Description                                                   |
| ---------------------- | ------ | ------------------------------------------------------------- |
| `external_patient_id`  | string | Your `partner_patient_id`, prefixed with your partner ID      |
| `parchment_patient_id` | string | Parchment's patient ID                                        |
| `url`                  | string | Link to the patient in the Parchment portal                   |

## Status Codes

| Code  | Status                | Description                                          |
| ----- | --------------------- | ---------------------------------------------------- |
| `200` | OK                    | Patient already exists; existing patient returned    |
| `201` | Created               | Patient created                                      |
| `202` | Accepted              | Demographic conflicts found; matching patient returned |
| `400` | Bad Request           | Patient not created, e.g. IHI already assigned       |
| `401` | Unauthorized          | Token invalid, or missing `create:patient` scope     |
| `409` | Conflict              | More than one patient matches the `partner_patient_id` |
| `422` | Unprocessable Entity  | Request validation failed                            |
| `500` | Internal Server Error | Unexpected server error                              |

## Validation

| Field                | Rule                                                                  |
| -------------------- | --------------------------------------------------------------------- |
| `partner_id`         | Required. Your registered partner ID, per environment                 |
| `partner_patient_id` | Required. 1–150 characters, unique in the organization                |
| `given_name`, `family_name` | Required. Not empty                                        |
| `phone`              | Australian mobile only (`04`/`05`, or `+61`/`61` prefix). Spaces, dashes and brackets are stripped |
| `ihi_number`         | Optional. Exactly 16 digits                                           |
| `postcode`           | Exactly 4 digits                                                      |
| `sex`, `state`       | Case-insensitive. `state` also accepts the full name                  |

## Notes

- Use `external_patient_id` from the response as the stored ID; a prefixed value is not double-prefixed.
- Send `australian_street_address` or `australian_address`; both are accepted.
- Log `requestId` for support requests.
