---
openapi: "GET /v1/organizations/{organization_id}/custom-drugs"
---

Returns the **organization-level** custom drug catalog. Personal (user-level) drugs are not included; use the user-level list for a prescriber's combined view.

Pass `?custom_product_id=` to return only the drug with that exact id.

## Notes

- Requires the `read:custom_drug` scope and an owner or admin token user.
- Use each drug's `custom_drug_id` to update, delete, or prefill the prescription form.
- Fields not set on a drug are omitted from the response.
