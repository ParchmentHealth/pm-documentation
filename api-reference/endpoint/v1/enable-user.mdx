## Overview

Enables the user so they can sign in again. Roles stay `member`; restore roles with [Update User Roles](/api-reference/endpoint/v1/update-user-roles). No request body.

Idempotent: a user who is already enabled returns `200` with `"User is already enabled"`.

Requires the `update:user` scope.

## Response Fields

| Field     | Type   | Description            |
| --------- | ------ | ---------------------- |
| `user_id` | string | Parchment's user ID    |

## Status Codes

| Code  | Status                | Description                                   |
| ----- | --------------------- | --------------------------------------------- |
| `200` | OK                    | User enabled, or already enabled                |
| `400` | Bad Request           | Target user has no email address              |
| `401` | Unauthorized          | Token invalid, or missing `update:user` scope |
| `404` | Not Found             | User not found                                |
| `500` | Internal Server Error | Unexpected server error                       |
